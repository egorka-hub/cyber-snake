# КиберЗмейка

Терминальная «Змейка» на Go в стиле симулятора сетевой безопасности. Змейка собирает пакеты данных и обходит вредоносное ПО. С каждым уровнем вирусов становится больше, а игра ускоряется.

## Правила

- `▶` — голова змейки, `○` — её тело.
- `●` — еда (пакет данных). Каждый съеденный пакет даёт +1 к счёту, и змейка становится длиннее.
- `✗` — вредоносное ПО. Столкновение с ним завершает игру.
- Игра также заканчивается, если змейка врезается в стену или в саму себя.
- Каждые 5 очков повышается уровень: на поле появляется ещё один вирус, а скорость растёт (шаг сокращается со 100 до 40 мс).
- Текущие счёт и уровень показаны в верхней рамке поля.

## Управление

| Клавиша | Действие |
|---|---|
| `↑` `↓` `←` `→` или `W` `A` `S` `D` | Движение |
| `R` | Перезапуск после окончания игры |
| `Esc` или `Q` | Выход |

Клавиши работают и в русской раскладке (`Ц` `Ф` `Ы` `В`, `К`, `Й`).

## Требования

- Go 1.26 или новее
- Терминал с поддержкой Unicode (macOS, Linux или Windows)

## Сборка и запуск

```bash
git clone https://github.com/egorka-hub/cyber-snake.git
cd cyber-snake
go mod download
go build -o cyber-snake .
./cyber-snake
```

Можно запустить и без сборки бинарника:

```bash
go run .
```
